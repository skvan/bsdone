# 技术参考文档（docs/tech）

> **维护口径**：文档可能存在滞后，**一切以代码为准**。如发现与代码不一致，请通过 [Issue](https://github.com/skvan/bsdone/issues/new/choose) 反馈或提交 PR 修正。
>
> **更新方式**：重大功能变更后，可按需从 RepoWiki 重新提炼同步（保持本目录结构不变）。
