# 个人驾驶舱配置

## 表：bs_user_clubhouse_config

按“用户 + 租户”保存自由画布驾驶舱的模块顺序、显示开关、桌面像素坐标/尺寸与数据选择；几何由服务端白名单范围校验，手机与紧凑端只使用数组顺序。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | bigserial | 主键 |
| `user_id` | bigint | 用户 ID |
| `tenant_id` | bigint | 租户 ID |
| `config_json` | text | 校验后的 JSON 配置 |
| `config_version` | integer | 配置版本，首次为 1，每次保存递增 |
| `created_by` / `created_at` | 审计 | 创建人/时间 |
| `updated_by` / `updated_at` | 审计 | 更新人/时间 |
| `deleted_by` / `deleted_at` | 软删 | 预留；当前只更新不删除 |

唯一约束：`(user_id, tenant_id) WHERE deleted_at IS NULL`，索引名 `ux_bs_user_clubhouse_config_user_tenant`。

迁移：`V20261021180000__user_clubhouse_config.sql`。

## config_json 结构

```json
{
  "version": 4,
  "layout": "v4-board",
  "modules": [
    { "key": "ranks", "enabled": true, "x": 0, "y": 0, "width": 1216, "height": 220 },
    { "key": "evaluation", "enabled": true, "x": 0, "y": 236, "width": 1216, "height": 700 },
    { "key": "milestones", "enabled": true, "x": 0, "y": 952, "width": 1216, "height": 500 },
    { "key": "performance", "enabled": true, "x": 0, "y": 1468, "width": 800, "height": 500 },
    { "key": "teams", "enabled": true, "x": 816, "y": 1468, "width": 400, "height": 300 },
    { "key": "schedule", "enabled": true, "x": 0, "y": 1984, "width": 800, "height": 560 },
    { "key": "about", "enabled": true, "x": 816, "y": 1984, "width": 400, "height": 280 },
    { "key": "recentGames", "enabled": true, "x": 0, "y": 2560, "width": 800, "height": 320 },
    { "key": "quickLinks", "enabled": true, "x": 816, "y": 2560, "width": 400, "height": 220 }
  ],
  "milestones": {
    "metricKeys": ["batting.h", "batting.rbi", "batting.sb", "batting.gp", "pitching.ip", "pitching.so"]
  },
  "performance": { "metricKey": "batting.avg", "viz": "line" },
  "ranks": [
    { "metricKey": "batting.avg" },
    { "metricKey": "batting.h" },
    { "metricKey": "batting.obp" },
    { "metricKey": "batting.rbi" }
  ]
}
```

- 画布逻辑宽度 1216px，任意两个启用模块至少间隔 16px；`x/y/width/height` 均为整数像素。前端拖动吸附 8px。
- `modules` 数组顺序 = 手机/紧凑端单列顺序、设置抽屉顺序和键盘顺序；桌面自由布局只看 `x/y/width/height`。
- `width` 必须在该模块 `minWidth`–1216 之间，`height` 在 `minHeight`–1600 之间；`x >= 0`、`y >= 0`、`x + width <= 1216`、`y <= 12000`。默认/最小尺寸见 `ClubhouseModuleCatalog`。
- 桌面高度是固定外框高度；内容超出时前端模块内部滚动，不自动撑高、不与邻居重叠。手机/紧凑端忽略高度，按内容自适应。
- 服务端保存前用 `ClubhouseModuleCatalog` 校验模块白名单、重复项与几何范围，用 `ClubhouseMetricCatalog` 校验指标白名单、图表兼容性、排名数量与重复项。
- 启用模块之间发生重叠（含间距不足 16px）时，按数组顺序把后出现模块下移到已占用区域底部（x=0），再返回规范化结果；禁用模块保留几何但不参与重叠检测。
- 未提供的模块会按默认顺序补到数组末尾，放在所有模块底部；九个模块始终完整落库。允许全部 `enabled=false`。
- `version:1` / `layout:v3-fixed`、`version:2` 以及 `version:3` / `layout:v3-modular` 的旧配置读取时保留指标、排名、模块顺序与开关，把旧列宽/行高迁移为像素几何并装箱，返回 v4；GET 不写库。
- 旧列宽转像素：`round(span * (1216 + 16) / 12) - 16`；旧高度 0 取目录默认高度，非 0 取 `rows * 10` 并收敛到最小/最大高度。
- 保存使用 PostgreSQL `ON CONFLICT (user_id, tenant_id) WHERE deleted_at IS NULL` 原子 upsert，避免并发首次保存撞部分唯一索引。
- 读取到非法/损坏 JSON 时回退默认配置但不在 GET 中写库；下次保存时覆盖。
- 默认排名不包含全垒打；全垒打只作为表现图可选指标，不进入队内排名。
- 本批不新增表或迁移，仍使用 `V20261021180000__user_clubhouse_config.sql`。
