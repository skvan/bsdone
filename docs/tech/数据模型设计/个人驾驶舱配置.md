# 个人驾驶舱配置

## 表：bs_user_clubhouse_config

按“用户 + 租户”保存模块化驾驶舱的模块顺序、显示开关、桌面宽高与数据选择；宽高由服务端白名单范围校验，手机端忽略宽高。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | bigserial | 主键 |
| `user_id` | bigint | 用户 ID |
| `tenant_id` | bigint | 租户 ID |
| `config_json` | text | 校验后的 JSON 配置 |
| `config_version` | integer | 配置版本，首次为 1，每次保存递增 |
| `created_by` / `created_at` | 审计 | 创建人/时间 |
| `updated_by` / `updated_at` | 审计 | 更新人/时间 |
| `deleted_by` / `deleted_at` | 软删 | 预留；当前只更新不删除 |

唯一约束：`(user_id, tenant_id) WHERE deleted_at IS NULL`，索引名 `ux_bs_user_clubhouse_config_user_tenant`。

迁移：`V20261021180000__user_clubhouse_config.sql`。

## config_json 结构

```json
{
  "version": 3,
  "layout": "v3-modular",
  "modules": [
    { "key": "ranks", "enabled": true, "width": 12, "height": 0 },
    { "key": "evaluation", "enabled": true, "width": 12, "height": 0 },
    { "key": "milestones", "enabled": true, "width": 12, "height": 0 },
    { "key": "performance", "enabled": true, "width": 8, "height": 0 },
    { "key": "teams", "enabled": true, "width": 4, "height": 0 },
    { "key": "schedule", "enabled": true, "width": 8, "height": 0 },
    { "key": "about", "enabled": true, "width": 4, "height": 0 },
    { "key": "recentGames", "enabled": true, "width": 8, "height": 0 },
    { "key": "quickLinks", "enabled": true, "width": 4, "height": 0 }
  ],
  "milestones": {
    "metricKeys": ["batting.h", "batting.rbi", "batting.sb", "batting.gp", "pitching.ip", "pitching.so"]
  },
  "performance": { "metricKey": "batting.avg", "viz": "line" },
  "ranks": [
    { "metricKey": "batting.avg" },
    { "metricKey": "batting.h" },
    { "metricKey": "batting.obp" },
    { "metricKey": "batting.rbi" }
  ]
}
```

- `modules` 数组顺序即展示顺序；持久化 `key`、`enabled`、`width`、`height`。
- `width` 为整数列数，必须在该模块 `minSpan`–12 之间；缺省取目录默认列宽（队内坐标/总体评价/生涯里程碑 12，数据表现/接下来的比赛/最近战报 8，代表球队/关于我/快捷入口 4）。最小列宽分别为 6/8/8/6/4/6/4/6/4。
- `height` 为整数 0–80，单位 10px；`0` 表示随内容自适应，非 0 表示最小高度。内容实际更高时前端仍会自然增高，不裁切。
- 服务端保存前用 `ClubhouseModuleCatalog` 校验模块白名单、重复项与宽高范围，用 `ClubhouseMetricCatalog` 校验指标白名单、图表兼容性、排名数量与重复项。
- 未提供的模块会按默认顺序补到数组末尾，并使用默认宽高；九个模块始终完整落库。允许全部 `enabled=false`。
- `milestones.metricKeys` 只持久化 1–6 个白名单指标；缺失/空数组回退默认 6 项，未知/重复/超过 6 项拒绝。
- `version:1` / `layout:v3-fixed` 以及 `version:2` 旧配置读取时保留指标、排名、模块顺序与开关，补默认模块宽高并返回 v3；GET 不写库。
- 保存使用 PostgreSQL `ON CONFLICT (user_id, tenant_id) WHERE deleted_at IS NULL` 原子 upsert，避免并发首次保存撞部分唯一索引。
- 读取到非法/损坏 JSON 时回退默认配置但不在 GET 中写库；下次保存时覆盖。
- 默认排名不包含全垒打；全垒打只作为表现图可选指标，不进入队内排名。
- 本批不新增表或迁移，仍使用 `V20261021180000__user_clubhouse_config.sql`。
